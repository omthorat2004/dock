# Dock API

FastAPI + MongoDB backend for Dock. See `../.claude/skills/backend-fastapi` for the
conventions this codebase follows.

## Setup

Requires Python 3.12+, Poetry, and MongoDB on `localhost:27017`.

```bash
cp .env.example .env
poetry install
poetry run fastapi dev src/app/main.py   # http://localhost:8000/docs
```

## Endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/api/v1/health` | Liveness probe |
| POST | `/api/v1/auth/register` | Create an account, set auth cookies |
| POST | `/api/v1/auth/login` | Sign in, set auth cookies |
| POST | `/api/v1/auth/refresh` | Rotate the session from the refresh cookie |
| POST | `/api/v1/auth/logout` | Revoke the session, clear cookies |
| GET | `/api/v1/auth/me` | The signed-in user |
| POST | `/api/v1/users/api-key` | Store the caller's provider key + model |
| DELETE | `/api/v1/users/api-key` | Clear the stored provider key |
| POST | `/api/v1/spaces` | Create a space for one lesson |
| GET | `/api/v1/spaces` | The caller's spaces, as summaries |

## Spaces

One space is one lesson, stored as a single nested document:

```
Space { user_id, lesson_name, topics[], created_at, updated_at }
  Topic { topic_name, youtube_links[], session }
    TopicSession { session_id, limit_reached, created_at, updated_at }
```

`POST /spaces` takes `{ lesson_name, topics: [str] }`, topic names only; videos
and sessions are server-owned. `lesson_name` is not unique (a student may
re-share a lesson when their syllabus changes), `_id` is generated by Mongo, and a
topic's `session_id` is minted on the first chat rather than at creation.

`GET /spaces` returns summaries: `{ id, lesson_name, topic_count, created_at,
updated_at }`, newest first, never the topics themselves. The count is computed
in Mongo with a `$size` projection.

## Auth

A 15-minute access token and a 30-day refresh token, both JWTs with a `type` claim,
both delivered as httpOnly cookies. Refresh tokens are stored hashed and rotated on
every use; replaying a rotated token revokes every session for that user.
